# CERT.OS v1.0.0

CERT.OS is a free certification practice exam simulator for Windows. It covers twelve IT certifications with 200 questions each, scored against the real cert pass thresholds, all wrapped in a CRT terminal aesthetic. It runs completely offline, with no account and no telemetry.

## Install

Download `CERT.OS.exe`, double click, run. Windows SmartScreen will warn about an unsigned binary on first launch. Click **More info**, then **Run anyway**. Verify the SHA-256 against the value above if you want to be sure.

## Known limitations

- **A+ is on the V14 codes** (220-1101 / 220-1102). The V15 migration is planned for v1.1.
- **No Mac or Linux build yet.** Both are planned.
- **Not code signed yet.** This is why SmartScreen warns on first launch (see Install above).
