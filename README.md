# CERT.OS

CERT.OS is a free, offline certification practice exam simulator for Windows. It covers twelve IT certifications with 200 questions each, scored against the real exam pass thresholds, wrapped in a CRT terminal aesthetic.

## Certifications covered

| Certification | Code | Pass |
|---------------|------|------|
| CompTIA A+ Core 1 | 220-1101 | 75% |
| CompTIA A+ Core 2 | 220-1102 | 78% |
| CompTIA Network+ | N10-009 | 80% |
| CompTIA Security+ | SY0-701 | 83% |
| Cisco CCNA | 200-301 | 82% |
| Microsoft MS-102 | MS-102 | 70% |
| Microsoft AZ-900 | AZ-900 | 70% |
| CompTIA ITF+ | FC0-U61 | 65% |
| CompTIA Linux+ | XK0-005 | 73% |
| CompTIA Server+ | SK0-005 | 75% |
| AWS Cloud Practitioner | CLF-C02 | 70% |
| ITIL 4 Foundation | ITIL4-F | 65% |

## Install

Download `CERT.OS.exe`, double click, run. Windows SmartScreen will warn about an unsigned binary on first launch. Click **More info**, then **Run anyway**. Verify the SHA-256 against the value below if you want to be sure.

**SHA-256 (`CERT.OS.exe`, 41.83 MB):**

```
11cebe09611ded67ca8b5d28b8b58d7433dbe40c4b6c5aaf6c5c51bca2fd868a
```

## System requirements

- Windows 10 or 11, 64-bit
- No internet connection required. CERT.OS runs entirely offline, with no account and no telemetry.

## Known limitations

- **A+ is on the V14 codes** (220-1101 / 220-1102). The V15 migration is planned for v1.1.
- **No Mac or Linux build yet.** Both are planned.
- **Not code signed yet.** This is why SmartScreen warns on first launch (see Install above).
